<mission>

<execution_constraints>
1. Locate the exact figure and panel identified by the target metadata. Ignore all other charts, tables, and visual objects in the image.
2. Use caption and panel metadata as strict constraints. Do not extract panels whose panel metadata has `"num": false`.
3. Extract every table-like dataset from every remaining extractable panel. If the figure has no distinct panels or the data comes from the whole figure, designate the panel as null.
4. MANDATORY SERIES BINDING: Every object in the `tables` array MUST be explicitly linked to a specific data series via the `"series_name"` field. Identify the name using the chart's legend. 5. TEXT OVERLAYS SCOPE RESOLUTION: Scientific charts contain explicit text written directly on the plot area. You MUST classify and extract them based on their scope:

   - POINT-LEVEL: If the text is attached to a specific data point, bar, or category (e.g., statistical significance markers like `*`, `**`, `***`, or explicit numerical value callouts written above bars), you MUST dynamically add a column named "Annotation" to the `columns` array and place the text in the exact row corresponding to that point/bar. 6. EXTREMA PRECISION: When reading values from lines/bars, pay extreme attention to local maxima (peaks), local minima (troughs), and boundary limits. Do not artificially flatten peaks. If a peak visually reaches a major tick mark, accurately reflect this.
7. Read values directly according to the explicit axis scales. Copy units exactly. Do not calculate, infer, normalize, or guess.
8. If specific values, axis labels, or units are unreadable (e.g., blurry text), output `null` for that cell and explicitly log a descriptive warning in the `warnings` array.
9. If no relevant chart data can be extracted, log this in the final `status`.
</execution_constraints>

<extraction_rules>
<rule name="Discrete_Categorical">
<definition>Charts mapping discrete categories to scalar values (e.g., Bar charts, Pie charts).</definition>
<action>Columns must include the category axis and the value axis. Check for error bars. If present, dynamically add an error column (e.g., "Error Bound") to the `columns` array and extract the error value into every row. Extract explicit text written above bars into the "Annotation" column.</action>
</rule>

<rule name="Discrete_Coordinates">
<definition>Charts representing sets of explicit tuples with physical markers (e.g., Scatter plots, line plots with distinct dots/squares/triangles).</definition>
<action>Columns must represent the coordinates (e.g., X and Y). Extract the precise coordinates ONLY for the center of every visible physical marker. IGNORE any unmarked trendline or fit-curve — do not sample arbitrary empty spaces along it.</action>
</rule>

<rule name="Continuous_Curves">
<definition>Continuous signal approximations WITHOUT explicit point markers (e.g., pure Line charts, UV-vis spectra, smooth kinetic curves).</definition>
<action>Columns must represent the axes (e.g., X and Y). Extract structural key points (global/local maxima, minima, axis intercepts). Additionally, sample approximately 10 equally spaced points along the X-axis to capture the curve's overall shape. Ensure highest peaks are captured exactly.</action>
</rule>

<rule name="Distribution_And_Density">
<definition>Charts mapping ranges/coordinates to frequencies/intensities (e.g., Histograms, Boxplots, Heatmaps).</definition>
<action>Adapt columns logically. For Histograms: `bin_start`, `bin_end`, and `frequency`. For Boxplots: `category`, `min`, `q1`, `median`, `q3`, `max`. For Heatmaps: `x`, `y`, and `z_intensity`.</action>
</rule>
</extraction_rules>
