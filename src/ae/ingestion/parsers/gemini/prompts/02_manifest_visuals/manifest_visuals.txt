### 1. Filtering (`visuals` vs `discarded_ids`)
- **Keep (`visuals`)**: Blocks containing extractable data—tables (`table`), quantitative plots/spectra (`chart`), 2D chemical structures/schemes (`molecular_structure`), or combinations thereof (`mixed`).
- **Discard (`discarded_ids`)**: Blocks without extractable tabular, numerical, or 2D structural data (graphical abstracts/TOCs, photographs, microscopy/gels, 3D protein/docking renders, conceptual cartoons).
- **Multi-page continuations & split figures**: When a visual (table, chemical scheme, chart, or composite figure) spans multiple adjacent pages:
  - **Table continuations** (caption usually on first page): merge all spanned pages into the primary table's `pages` (e.g., `Table_1` on p. 3 continued as `Unlabeled_p4_1` on p. 4 -> `Table_1` with `pages: [3, 4]`; add `Unlabeled_p4_1` to `discarded_ids`).
  - **Figure & scheme continuations** (caption usually on last page): when an uncaptioned scheme, scaffold, or substituent table on page N belongs to the same figure or chemical series as the captioned figure on page N+1 (e.g., `Unlabeled_p6_1` containing compounds 19–23 and Ar substituent table on p. 6, followed by `Fig.-10` containing compounds 24–33 on p. 7):
    - Merge both pages into the captioned visual (`Fig.-10` with `pages: [6, 7]`).
    - Add the uncaptioned placeholder (`Unlabeled_p6_1`) to `discarded_ids`.
    - In `description`, synthesize the scope from ALL spanned pages (e.g., "Chemical structures of derivatives 19–33 with Ar substituent table").
  - **Shared R-group tables & legends**: When a substituent table or scaffold is placed on page N and the corresponding core structures continue on page N+1 (or vice versa), merge them into the single designated visual ID.
  - **Standalone uncaptioned structures**: Only keep an `Unlabeled_*` placeholder as an independent visual if it is truly isolated and does NOT belong to the series, scaffold, or legend of any neighboring figure/table.

### 2. High-Level Content Index (`description`)
Write a concise 1–2 sentence **metadata summary** (max 35 words) indicating *what kinds of data and entity IDs* the visual contains, so an agent knows whether to invoke the visual parser.
- **Metadata only — do NOT parse values**: State the presence of data categories, column/axis names, and compound ID ranges, but do NOT transcribe actual numerical values, specific reaction reagents/temperatures, substituent formulas, or SMILES.
- **What to index by modality**:
  - **`table`**: Compound/row ID ranges (e.g., `6a–6f`), column header names/metrics (e.g., `MIC`, `IC50`, `yield %`), target organisms/assays, and whether cells contain 2D structures.
  - **`molecular_structure`**: Depicted compound IDs/series (e.g., `1`, `2a–2l`), presence of 2D structures or Markush R-group legends, reaction transformations (`7a–b -> 8a–b -> 10a–b`), and whether conditions/yields/bioactivity notes are printed on the scheme.
  - **`chart`**: Plot/spectrum type, `Y vs X` axis variables, compared series/compound IDs, and presence of fitted metrics (e.g., $IC_{50}$, $K_d$).
  - **`mixed` / multi-panel**: Brief panel-by-panel tag of modality and scope (e.g., `(a) dose-response curves for 3a–3c; (b) 2D structure of lead 3a`).
