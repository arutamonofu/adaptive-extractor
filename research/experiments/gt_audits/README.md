# Реестр аудитов расхождений разметки (`GT Audits`)

Единый архив ручной сверки извлечённых данных с эталонной разметкой (*Ground Truth*, GT) по доменам проекта. Реестр фиксирует первопричину каждого расхождения (ошибка GT, ошибка экстрактора, допустимое разночтение или данные только на иллюстрации).

## 1. Унифицированная схема CSV

Файлы [`nanozymes.csv`](nanozymes.csv) и [`benzimidazole_antibiotics.csv`](benzimidazole_antibiotics.csv) используют общую 12-колоночную схему (UTF-8):

| Колонка | Описание |
| :--- | :--- |
| `domain` | Предметный домен (`nanozymes`, `benzimidazole_antibiotics`) |
| `iteration` | Итерация аудита (`iter_1`, `iter_2`) |
| `split` | Сплит статьи (`train`, `train_manual`, `val`, `excluded_visual`, `other`) |
| `doc_id` | Идентификатор статьи / PDF без расширения |
| `discrepancy_type` | Тип расхождения: `value`, `inclusion`, `format`, `visual_missing`, `other` |
| `field` | Поле схемы или `row` (включение/исключение всей строки) |
| `scope_detail` | Локализация в статье, номер строки GT, серия соединений или класс |
| `gt_value` | Значение или состав строк в исходном GT |
| `extracted_value` | Значение или состав строк в выводе экстрактора |
| `verdict_code` | Нормализованный код вердикта *(см. ниже)* |
| `verdict_raw` | Исходная формулировка вердикта |
| `resolution_and_notes` | Итоговое решение и доказательное обоснование по PDF |

**Коды вердиктов:** `gt_error` (ошибка в GT, экстрактор прав), `extractor_error` (ошибка экстрактора), `both_valid` (допустимое разночтение), `both_wrong` (ошиблись оба), `visual_missing` (данные только на картинке), `gt_corrected` (принята правка GT во 2-й итерации), `gt_kept` (оставлен текущий GT), `discrepancy_open` (рабочий кейс без финальной метки).

## 3. Домен `nanozymes` (2-й семестр, текстовый PoC)

Всего в [`nanozymes.csv`](nanozymes.csv) зафиксировано 239 кейсов по 34 статьям:

| Вердикт | Кейсов | Главные проблемные поля |
| :--- | :---: | :--- |
| `discrepancy_open` *(открытые расхождения)* | 167 | `surface` (41), `syngony` (28), `temperature` (27), `ccat` (19), `c_min/c_max` (18), `formula` (17), `cconst` (12) |
| `gt_error` *(модель права, ошибка GT)* | 44 | Ошибочная кристаллиграфия `syngony` и `ph`, незафиксированные концентрации |
| `visual_missing` *(данные только на графике)* | 26 | Концентрации и размеры на графиках без дублирования в тексте |
| `extractor_error` *(ошибка модели)* | 2 | Ложное исключение прекурсора Ni(OH)2 при наличии констант |

### Выработанные правила разметки и правки GT (`nanozymes`)

1. **Политика включения:** фиксировать эксперименты только при наличии рассчитанной константы (Km или Vmax), включая отдельные компоненты композита при собственных измерениях и исключая прикладные bioassay.
2. **Семантика полей:** `surface` — только органическая модификация либо структурно интегрированный темплат/стабилизатор; `length`/`width`/`depth` — только TEM/SEM (для сфер диаметр дублируется, XRD-кристаллиты исключаются); `formula` — базовая неорганическая формула без фаз и органики.
3. **Запрет расчётов и пересчёта единиц:** концентрации и единицы (`0.5 mg`, `8 mM`) берутся дословно без пересчёта на объём смеси; газообразный O2 не пишется в `reaction_type`; запрещены вывод `syngony` по внешним справочникам и запись `room temperature` числом; при расхождении с GT приоритет имеет текст статьи.
4. **Правки выборки и GT:** добавлены поля `c_min_unit`, `c_max_unit`; внесены 52 точечные правки GT; исключены 9 графических статей (`c1cc11943e`, `j.bios.2014.07.048`, `j.snb.2019.127106`, `j.colsurfa.2011.08.008`, `j.nantod.2022.101421`, `nnano.2007.260`, `s00604-019-3395-8`, `s1227402026805`, `srep35344`) и ещё 2 статьи из пула `few-shot` (`acsami.0c07886`, `S00604-017-2198-Z`).

## 4. Домен `benzimidazole_antibiotics` (3-й семестр, мультимодальный MVP)

### Итерация 1 (`val` + `train`: 55 кейсов)

| Сплит | Всего | `gt_error` | `extractor_error` | `both_valid` | `both_wrong` | Основные поля расхождений |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| `val` (6 статей) | 24 | **13** | 5 | 5 | 1 | `row` (8), `smiles` / `smiles_canonical` (5), `bacteria` (6), `target_value`/`relation` (5) |
| `train` (6 статей) | 31 | **13** | 5 | 12 | 1 | `smiles` / `smiles_canonical` (15), `bacteria` (5), `row` (5), `target_units`/`value` (4) |

Выявленные системные паттерны:
- **Таутомерия 5/6-NH бензимидазолов (`1570180811666140725185713`):** классическая канонизация RDKit без нормализации таутомеров считает эквивалентные таутомеры разными SMILES — учтено в валидаторе [`chemistry.py`](../../../src/ae/core/schema/domain_validators/chemistry.py).
- **Дефекты исходных схем PDF (`antibiotics10081002`, `RJC.2023.1638382`):** перепутанные R/R1 и пятивалентный азот на Scheme 9, потерянное кольцо на Fig.-10 — экстрактор исправляет структуру по тексту, тогда как GT порой копировал опечатку рисунка.
- **Артефакты ручной разметки GT (`s41598-022-21435-6`, `j.molstruc.2021.130566`):** автозаполнение Excel инкрементировало код штамма (ATCC 25923 → 25926), в GT попадали нецелевые индолы/имидазолы и цифры из соседнего предложения.

### Итерация 2 (15 принятых решений по GT)

Все 15 пакетов (13 `gt_corrected`, 2 `gt_kept`) по 7 документам легли в очищенный эталон контрольного прогона [`2026-11-21_benzimidazole_post_audit_eval`](../2026-11-21_benzimidazole_post_audit_eval/report.md):
- **Чистка включений:** удалены 18 строк не-бензимидазольных прекурсоров (`j.bmcl.2018.03.046`) и ошибочные диаметры зон ингибирования 6b (`jccs.202000418J` → оставлены реальные MIC 6d); добавлены пропуски 4d / MRSA N315 и 8h / S. aureus ATCC 29213 (8 µg/mL, Table 4 в `j.ejmech.2020.112996`); дублирующая серия Table 4 для 8b/8c/8i оставлена дедуплицированной (`gt_kept`).
- **Исправление значений:** обновлён SMILES 5b на N-этил (`acsomega.2c06142`), исправлены 11 строк E. coli JM109 + 14m и значения 15j (0.25 ± 0.02), 17a (16) в `j.ejmech.2016.01.052`, согласован ID 9c в `acs.jafc.1c02545`.
- **Унификация `bacteria`:** раскрыты сокращения по сноскам в 144 строках `j.bmcl.2018.03.046`, выровнены 49 строк Table 4 (`j.ejmech.2020.112996`), 48 строк `j.ejmech.2016.01.052` и 7 строк `s41598-022-21435-6` (при опечатке в PDF `Staphylococcus. aureus` сохранён чистый эталон — `gt_kept`).
